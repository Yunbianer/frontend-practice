运行说明

本页说明项目如何运行、包含哪些功能，以及遇到报错时该怎么办。

一、如何运行（重要）

本项目通过代码读取本地的 JSON 数据文件。现代浏览器出于安全限制， 直接双击打开 HTML 文件（file:// 方式）会导致数据加载失败。 因此需要先在项目目录启动一个本地服务器，再用浏览器访问。

项目目录：c:\Users\18163\collect-form\final

  1. 打开 PowerShell，进入项目目录。
  2. 如果电脑装了 Python，运行下面这条命令： 
    python -m http.server 8000
    如果没有 Python，也可以用 Node 的方式： 
    npx serve
  3. 看到提示后，打开浏览器，访问 http://localhost:8000（或命令行显示的地址）。
  4. 点击页面里的导航即可在“首页 / 自习室 / 食堂”之间切换。
二、功能清单
1. 首页总览（index.html）
  • 顶部统计卡片：座位总数、空闲座位、今日访问、开放场馆，带数字滚动动画。
  • 人流趋势折线图（ECharts）：对比自习区与食堂区各时段人流。
  • 场馆使用率柱状图（ECharts）：颜色随使用率高低变化。
  • 本周访问趋势面积图（ECharts）。
  • 校园场馆三维导览（Three.js）：可拖动旋转、滚轮缩放，建筑高度对应使用率。
  • 最新通知公告列表。
2. 自习室查询（study.html）
  • 搜索：按自习室名称关键词实时搜索。
  • 筛选：按楼栋、状态、是否空调筛选，可组合使用。
  • 新增：点击“新增自习室”填写表单并保存。
  • 修改：点击卡片上的“修改信息”可编辑已有记录。
  • 数据保存在浏览器本地（localStorage），刷新不丢失；可一键“恢复默认数据”。
3. 食堂信息（canteen.html）
  • 各食堂繁忙度柱状图（ECharts）。
  • 搜索与菜系筛选。
  • 食堂卡片：评分、繁忙度、开放时间、人均、推荐菜。
三、错误提示说明

项目内置了完整的错误与状态提示，出现下列提示时按对应方法处理即可。

  1. “无法加载数据文件……需通过本地服务器运行”——说明你是直接双击打开的 HTML。 请回到“一、如何运行”，用本地服务器启动后再访问。
  2. “加载数据失败……请检查 data 文件是否存在”——检查 data 文件夹里的 dashboard.json、study.json、canteen.json 是否齐全。
  3. “三维场景加载失败：Three.js 库未成功引入”——一般是网络问题导致 CDN 没加载成功， 检查网络后刷新页面即可。
  4. 表单提示“请填写名称 / 空闲座位不能大于总座位”等——这是新增或修改时的校验提醒， 按提示修正内容后再保存。
  5. 数据改动后想还原——在自习室页面点击“恢复默认数据”，会清空本地改动并重新加载初始 JSON。
四、技术栈
  • HTML5 + CSS3（CSS 变量、媒体查询响应式）
  • JavaScript（ES6+）
  • Bootstrap 5（响应式布局、模态框、组件）
  • jQuery（DOM 操作与事件绑定）
  • ECharts 5（折线图、柱状图、面积图）
  • Three.js（三维校园场馆展示，含 OrbitControls 交互）
  • 本地 JSON 数据 + localStorage 持久化
